环境变量
========

环境变量应在启动 Python 进程前设置，至少应在首次导入 ``torch``、``torch_supa``
或 ``vllm_omni_supa`` 前完成设置。未特别说明时，布尔开关使用 ``0`` 表示关闭、``1``
表示开启。

壁仞硬件环境变量
----------------

这组变量控制 SUPA/BR2XX 设备可见性。

.. list-table:: 壁仞硬件环境变量
   :header-rows: 1
   :widths: 42 18 40

   * - 变量
     - 默认值
     - 作用
   * - ``SUPA_VISIBLE_DEVICES``
     - 未设置
     - 控制当前进程可见的 SUPA 设备，例如 ``0`` 或 ``0,1``。

修改环境变量后必须重新启动 vLLM Omni 进程；运行期间修改通常不会影响已经初始化的组件。
